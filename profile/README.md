## Overview

OneNote Sticky Notes Hub is a quick-note management concept built around floating notes and cross-device capture. It brings together screen pinning, keyboard shortcuts, and automatic notebook saving into a single workflow for users who need fast reminders without opening the full OneNote application.

---

## Essential Sticky Notes Features

- **Floating Quick Notes:** Create small note windows that stay on screen like physical sticky notes [citation:2][citation:3].
- **Keyboard Shortcut Capture:** Press Windows + Alt + N to create a new quick note even when OneNote is not running [citation:2][citation:7].
- **Screen Pinning:** Use "Always on Top" to keep important notes visible over other windows [citation:3][citation:15].
- **Automatic Notebook Saving:** Quick Notes are saved to the Quick Notes section in your default notebook for later search and organization [citation:2][citation:12].
- **Cross-Device Sync:** Access sticky notes on mobile through OneNote for iPhone and iPad, or through the web at onenote.com/stickynotes [citation:6].
- **Capture to Notebook:** Drag sticky notes onto OneNote pages or copy selected text into new sticky notes on iPad .

## What Sticky Notes Bring to Quick Capture Workflows

The feature provides a lightweight capture layer alongside the full OneNote application. Its structure supports both momentary reminders and more organized note-taking.

Quick Notes serve as the electronic equivalent of small yellow sticky notes. Unlike paper, they are instantly saved to the OneNote notebook, making them searchable and organizable later [citation:2][citation:3].

The keyboard shortcut removes friction. Pressing Windows + Alt + N creates a new quick note without switching to OneNote, which suits users who need to capture a thought while working in another application [citation:2][citation:7].

Screen pinning keeps important information visible. Notes marked "Always on Top" remain above other windows, useful for reference material or temporary reminders during a task [citation:3][citation:15].

Cross-device access varies by platform. On iPhone and iPad, Sticky Notes appear within the OneNote app. On Android phones, the Sticky Notes option is available in the phone layout, while tablet layouts may require filtering the homepage or using the web version [citation:6].

Desktop behavior differs from mobile. The standalone Sticky Notes app on Windows is separate from the OneNote desktop application, though notes sync through the same Microsoft account .

The web interface provides a fallback. Users can access synced sticky notes at onenote.com/stickynotes in any browser, which is useful when the desktop app does not display the Sticky Notes view [citation:6].

## Starting a Sticky Notes Session

**Prerequisites:** A compatible device, OneNote installed or web access, and a Microsoft account for sync.

1. **Check Compatibility:** Confirm OneNote is available on the target device and the account is signed in [citation:6].
2. **Obtain Access:** Use the GET button above to reach the designated project destination and review available information.
3. **Create a Quick Note:** Press Windows + Alt + N, or use View > New Quick Note from the OneNote menu [citation:2][citation:3].
4. **Pin if Needed:** Use Always on Top to keep the note visible over other windows [citation:15].
5. **Organize Later:** Close the note when done; it remains saved in the Quick Notes section of the default notebook [citation:2].
6. **Sync Across Devices:** Sign in with the same Microsoft account on mobile or web to access the same notes [citation:6].
